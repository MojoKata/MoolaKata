# The dev seed's avatars

Jane's and John's faces, cropped from Grant Wood's *American Gothic* (1930, Art Institute of
Chicago), which is in the public domain. Each is 64×64 pixels, PNG with 256 colours and no colour profile: the app's
largest avatar is 34 px, so they are sharp at twice that. The seed sets them as the users'
avatars (`seed.py`).
