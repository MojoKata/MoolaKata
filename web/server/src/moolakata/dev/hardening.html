MoolaKata hardening

Each row is one of the coverage page's areas. A finding counts in the area of the first code it names, or of its section when it names none. A module counts as mutation-tested once a run over it is settled, and as changed since when its content on main is no longer what the run settled. A module the CI baseline ran, not yet settled, reads baseline only, and baseline, changed since once its content is no longer what the baseline mutated: its survivors are stale, and its sweep runs it again. The path

Every step to the end of the sweep, in order (docs/hardening/path.toml). A row is checked when its pull request merges, and shows what changed in its areas at that merge. In the table above, Step gives each area's steps, and Swept whether its findings are closed (F), its mutation runs are current (M) and its sweep has merged (S).

Mutation runs

Each run as docs/hardening/mutation/ records it. First catch is the share of changes the tests caught on the area's first run (timeouts count as caught; changes no test reached count against). Settling then catches every survivor by a test or lists it as an equivalent.
