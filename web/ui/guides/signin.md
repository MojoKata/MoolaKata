# Sign In

## Username or email

Either one.

## Password

Ten wrong passwords in 15 minutes lock the username for a while.

## Code

When two-step sign-in is on, the six-digit code your authenticator app shows for MoolaKata. A new
one comes every 30 seconds, and each works once. Wrong codes count like wrong passwords, and the
fifth wrong one ends the sign-in: start again with your password.

## Recovery code

One of the ten codes you saved when you turned two-step on, if your phone is lost. Each works once.
With none left, ask an admin to reset your two-step sign-in.

## Forgot password?

Sends a link to choose a new one; it works once, for an hour. The answer is the same whether or
not the account exists.

## Account disabled

An admin made the account inactive. You can ask, once a week, to be made active again. The answer
is the same whatever the account, so it tells nobody whether one exists; a wrong password counts
like a wrong sign-in.
