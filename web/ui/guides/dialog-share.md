# Share

Who else has this item, and at which level. Nothing changes until **Save**.

## People

Every active user. **Read** sees everything and changes nothing; **Write** also changes what it
holds. Nobody but you deletes it, shares it or sees its keys.

## Via a group

Someone with access through a group is shown with the group's name.

## Groups

The same, for every member while they're in the group.

## People on a linked server {#linked-people}

The users of each server this one is linked with, under that server's name: it confirms who they
are. They can only **Read**. What you share reaches their server at its next exchange and shows
only in that household's window there, only to the people you name; nobody else there sees its
name or figures, and it can't be shared on from there.

## Include receipts {#include-receipts}

Off by default: receipts are large and personal. On, the item's receipts (an account's, a gift
plan's, a giving plan's, or a tax book's document files) cross to that server with the text read
from them; off, they see only how many receipts a transaction has. Shown only for what has files
to send.

## Share These Accounts Too

A portfolio's viewers see only the accounts in it that are shared with them. This shares the missing
ones you own, at Read.
