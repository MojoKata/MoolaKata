# A linked copy's access key

## The words {#words}

Twelve words from the BIP39 list, the last carrying a checksum: the only way into this link's copy.
MoolaKata keeps no copy of them, in any form. Save them in the household's password manager, where
the people this link's shares name can reach them. Whoever opens the copy first enters them, and
they open only what is shared with each person.

## I have saved the 12 words {#words-saved}

**Done** waits for this tick. If the words are ever lost, **Reset Copy** makes new ones, and the
copy is pulled again in full.
