# Waiting for Approval

Your email address is confirmed. An admin decides on each request for an account; you'll get an
email when they have, and can then sign in with the username and password you chose.

A confirmation link works once, for a day. When it has expired, ask for an account again from
the sign-in screen.

## Username

The username you asked for is checked only once your email is confirmed. When someone here has
it already, or asked for it first, choose another: lowercase letters, digits, dots, dashes or
underscores. **Send the Request** passes the request to the admins with the new one.
