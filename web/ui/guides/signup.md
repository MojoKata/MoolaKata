# Ask for an Account

This server lets people ask for an account. An admin approves or rejects each request; you'll get an
email either way.

## Your name {#display-name}

As others here will see it.

## Sex

Your person's (every user is one): it chooses the words for the family tree.

## Email address {#email}

A link to confirm it is sent here first. The request reaches the admins only once it is confirmed.
An admin may have limited sign-up to some email domains.

## Username

What you'll sign in with: lowercase letters, digits, dots, dashes or underscores.

## Password

At least the minimum length, and not a common password. You sign in with it once the request is
approved.
