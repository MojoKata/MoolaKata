# Your New Access Token

## Token

Shown only now: MoolaKata keeps only a fingerprint of it. Copy it into your assistant's MCP
settings, with the endpoint shown, as a bearer token: `Authorization: Bearer mkt_…`. Anyone holding it can read what it can until
it expires or you revoke it, so keep it out of chats and shared files. If you lose it, revoke it and
make another.
