# A tax document

## Kind {#direction}

**Received**: a W-2, a 1099, a 1098 and the like. **Filed**: the return as filed, an
acknowledgement, a notice or a reply.

## Document {#form}

Which document it is.

## Issued by {#issuer}

The employer, broker, bank or tax authority.

## Filing

For a filed document: the filing it belongs to.

## Account

For a received document: the account it reports on, if any, which marks the expected one
received.

## File

The PDF or a photo, kept encrypted with your receipts.

## Notes

What it says, and what you did about it.
