# Copy as scenario

A new budget of yours with the same accounts and plan from this month, to try another method or
plan beside the one you follow, which doesn't change.

## Name

Such as _Household, envelope_.

## Method

**Tracking** or **envelope**. Each plan line becomes the same amount, planned or assigned each month.

## Bring this month's moves {#bring-this-month-s-moves}

This month's moves come along, so the scenario starts from where the budget stands. Moves to or from
To Budget come along only into an envelope budget.
