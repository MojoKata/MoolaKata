# Copy as Scenario

A new budget of yours with the same accounts and plan from this month, to try another method or
plan beside the one you follow, which doesn't change. Only the accounts you can see come along; a
reserve held in one that doesn't keeps its target and is held _in the budget's accounts_.

## Name

Such as _Household, envelope_.

## Method

**Tracking** or **envelope**. Each plan line becomes the same amount, planned or assigned each month.

## Bring this month's moves {#bring-this-month-s-moves}

This month's moves come along, so the scenario starts from where the budget stands. Moves to or from
To Budget, or into a card's payment line, come along only into an envelope budget, and a card's only
when you can see the card. Landed money given to a reserve or kept as the account's own comes along
when you can see the account it landed in.
