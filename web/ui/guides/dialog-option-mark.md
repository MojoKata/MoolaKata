# Marking an option

A price for an option the price source doesn't serve, used until the source has a close for it. Without a typed mark or a
close, an option is valued at its intrinsic value: what it would be worth exercised now.

## On {#mark-date}

The day the mark is for. It can't be in the future.

## Mark {#mark-price}

A share, as quoted: 4.20 for a contract worth 420.
