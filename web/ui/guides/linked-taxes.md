# Taxes

A tax book shared with you: its panels, as its filers' server worked them out. Everything here is read only and comes from that household's server; nothing is worked
out again here.

## Documents

The book's documents, each by its form and issuer. A document's file opens here when the book was
shared with **Include receipts** and the file has arrived; otherwise it stays home.

## The header strip {#strip}

Which server this comes from, that it is read only, when it last synced, and who unlocked it and
when it locks. **Lock now** locks it for everyone at once.
