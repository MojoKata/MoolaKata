# Receipts

The receipts that came with what this household shares with you: only for accounts its owner
shared with **Include receipts**. Each shows its payee, date and amount, as read where it was
uploaded; click one to open it. It is decrypted as it is shown, never written out in plain, and
checked against the fingerprint its source sent. One marked **not arrived** came without its file,
which is asked for again at each exchange; the rest of what is shared arrived without waiting
for it.

## The header strip {#strip}

Which server this comes from, that it is read only, when it last synced, and who unlocked it and
when it locks. **Lock now** locks it for everyone at once.
